# Figma import package

Everything needed to rebuild the portfolio as a Figma file, without the Figma
API. Generated by `npm run figma` from the site's own content and tokens — edit
the source, re-run, and these regenerate.

```
artboards/   7 SVGs — import as editable text and vector layers
tokens.json  design tokens — import as Figma Variables
```

## Why this package and not a live Figma file

The Figma Starter plan allows **20 MCP tool calls per month**. A design system
plus six screens needs far more than that, and every fix-and-retry costs
another call. These files sidestep the API entirely.

If you upgrade to a Professional seat (200 calls/day), say so and the same
content can be built natively instead — real component sets with variants,
variable collections with Light/Dark modes, and auto-layout, none of which SVG
can carry.

## 1. Fonts first

Both faces are already in Figma's font picker (they ship with Figma's Google
Fonts library), so nothing to install:

| Family | Styles used | Note |
|---|---|---|
| **Fraunces** | `SemiBold`, `SemiBold Italic` | no space in the style name |
| **Inter** | `Regular`, `Medium`, `Semi Bold` | **with** a space in `Semi Bold` |

Import the SVGs before changing any text — if a font is missing at import,
Figma substitutes it and the measured line breaks will shift.

## 2. Import the artboards

Drag all seven SVGs from `artboards/` onto a Figma page at once, or
**File → Import**.

| File | Size | What it is |
|---|---|---|
| `01-foundations.svg` | 1680×2560 | Colour tokens in both modes with measured contrast ratios, type ramp, spacing, radius |
| `02-components.svg` | 1680×1720 | Buttons (4 emphases × 3 sizes), tags, badges, chips, form fields incl. error and disabled, project card, nav, empty state |
| `03-home-desktop.svg` | 1440×5160 | Home — hero, domain strip, two featured projects, about, process, contact |
| `04-home-mobile.svg` | 390×2420 | Home at phone width — a real mobile layout, not a squeezed desktop |
| `05-work-index.svg` | 1440×1700 | Work index with the industry filter bar and card grid |
| `06-case-study.svg` | 1440×3020 | CropVibe — hero, meta bar, overview metrics, user insights |
| `07-404.svg` | 1440×900 | Not-found page |

Each `<g id="…">` becomes a **named Figma group** and each `<text>` an
**editable text layer**, so the layer tree arrives structured rather than as
one flattened blob.

## 3. Import the tokens as Variables

`tokens.json` is in [W3C design token](https://tr.designtokens.org/) format,
which the **Tokens Studio** plugin reads directly:

1. Plugins → **Tokens Studio for Figma** → *Import* → choose `tokens.json`
2. It creates three sets: `light`, `dark`, `global`
3. **Export to Figma → Variables**, mapping `light` and `dark` to two modes of
   one collection

You get `color/*` with both modes, plus `spacing/*`, `radius/*`, typography and
font families. Every colour token carries its CSS variable name as code syntax,
so Figma's Dev Mode shows `var(--accent)` — the same name the site uses.

## 4. Turn the groups into components

The component sheet is laid out so this is mechanical:

1. On `02-components.svg`, select a group such as `Button / primary / md — View my work`
2. **Create component** (⌥⌘K)
3. Select the row of related components → **Combine as variants**
4. Rename the variant property, e.g. `Emphasis=primary, Size=md`

Do buttons, tags, chips and form fields in that order — the screens reuse those
four most.

> SVG cannot carry auto-layout, variants or variable bindings. Expect to add
> auto-layout to the containers you intend to reuse; the spacing already sits
> on the 8px grid, so the values to type in are the ones in `tokens.json`.

## What was verified before these shipped

`npm run figma` fails the build on either of two conditions, checked by
measuring the rendered SVG in a real browser with the real fonts:

- **text outside its artboard** — anything past the edge
- **text buried under a shape painted later** — the failure a bounds-only check
  misses entirely, and the one that actually hid the hero headline behind the
  artboard panel during this build

Both are clean. Text is measured with canvas `measureText` including
letter-spacing, so wrapped lines break where they are drawn.

## Regenerating

```bash
npm run figma
```

Reads `src/data/*` and `src/styles/tokens.css` via `scripts/figma/`. Change the
site's content or colours and re-run — the artboards and tokens follow.
